# shared/protocol

Единый первоисточник по протоколу обмена «прошивка ↔ хост».

- `protocol.yaml` — описание команд, ответов и стримов.
- `generate_c.py` — кодогенерация C-заголовка для прошивки.
- `generate_py.py` — кодогенерация Python-модуля для хоста.

При изменении `protocol.yaml` ОБЯЗАТЕЛЬНО перегенерировать оба артефакта
и закоммитить — иначе прошивка и хост рассинхронизируются.
