# Протокол обмена

Бинарный протокол поверх UART/USB-CDC/TCP — **запланирован, в сборку не подключён**.
Документ описывает целевую структуру кадра; первоисточника-YAML и кодогенерации
в репозитории на сегодня нет. Текущий канал обмена — текстовый CLI ([cli.md](cli.md)).

См. также:
- [adr/0003-protocol-binary.md](adr/0003-protocol-binary.md) — почему бинарный.
- [cli.md](cli.md) — параллельный текстовый shell-канал на том же UART (для
  отладки в терминале и упрощённой интеграции GUI). Бинарный и текстовый
  протоколы независимы; парсер хоста выбирает один из них на сессию.

## Кадр
| Поле     | Размер | Описание                    |
|----------|--------|-----------------------------|
| SOF      | 1      | 0xA5                        |
| Len      | 2      | длина payload (LE)          |
| Cmd/Resp | 1      | код команды/ответа          |
| Seq      | 1      | номер запроса 0..255        |
| Payload  | N      | поля запроса/ответа         |
| CRC16    | 2      | CCITT-FALSE по Cmd..Payload |
