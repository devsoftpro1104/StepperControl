# ADR 0001. Использовать STM32 LL-драйверы вместо HAL

Дата: 2026-05-08
Статус: Принято

## Контекст
Для прошивки нужен предсказуемый по времени код управления шаговым двигателем.

## Решение
Использовать LL (Low-Layer) поверх CMSIS, без HAL.

## Последствия
+ Меньший размер кода, меньше скрытых таймингов.
+ Прямой доступ к регистрам, проще профилирование.
- Больше ручной работы при инициализации перифер.
- Сторонние middleware (USB-CDC) приходится переписывать или адаптировать.
