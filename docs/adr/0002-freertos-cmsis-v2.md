# ADR 0002. FreeRTOS-Kernel + CMSIS-RTOS v2

Дата: 2026-05-08
Статус: Принято

## Решение
Использовать FreeRTOS-Kernel напрямую (как submodule), а в коде приложения — обёртку CMSIS-RTOS v2.

## Последствия
+ Стандартизированный API, переносимость между ОС.
+ Удобная конфигурация через `FreeRTOSConfig.h`.
- Минимальный оверхед на обёртку — приемлемо.
