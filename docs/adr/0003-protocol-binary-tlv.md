# ADR 0003. Бинарный TLV-протокол

Дата: 2026-05-08
Статус: Принято

## Решение
Бинарный кадр SOF/Len/Cmd/Seq/Payload(TLV)/CRC16-CCITT.
Описание в `shared/protocol/protocol.yaml`, заголовки и парсеры — кодогенерация.

## Альтернативы
- JSON over UART — отброшен из-за стоимости парсинга и размера.
- Modbus RTU — отброшен: избыточен и плохо ложится на streaming-телеметрию.

## Последствия
+ Единый источник правды, синхронизация прошивки и хоста.
+ Малый размер, низкий CPU.
- Нужны генераторы и валидация YAML.
