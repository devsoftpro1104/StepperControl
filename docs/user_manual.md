# Руководство пользователя

## Подключение
1. Соединить плату по USB.
2. Запустить `controller_app`.
3. На вкладке «Соединение» выбрать порт → «Подключить».

## Управление двигателем
- Скорость, ускорение, направление — на панели «Мотор».
- Кнопки JOG ±, HOME, GOTO.
- Аварийный стоп — пробел или красная кнопка.

## Логи и телеметрия
- Графики тока/температуры/положения — вкладка «Телеметрия».
- Логи — нижняя панель, фильтрация по уровню.
