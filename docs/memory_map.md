# Карта памяти STM32F407

| Регион         | Начало      | Размер | Назначение                       |
|----------------|-------------|--------|----------------------------------|
| FLASH          | 0x08000000  | 1 MiB  | код прошивки                     |
| Bootloader     | 0x08000000  | 32 KiB | (резерв под будущий загрузчик)   |
| App            | 0x08008000  | 960 KiB| основное приложение              |
| Settings       | 0x080E0000  | 128 KiB| последний сектор — эмуляция EEPROM (в FLASH) |
| SRAM1          | 0x20000000  | 112 KiB| стек/куча/данные                 |
| CCMRAM         | 0x10000000  | 64 KiB | DMA-ограничение, для FreeRTOS task stacks |

См. [firmware/linker/stm32f407xx_flash.ld](../firmware/linker/stm32f407xx_flash.ld).
