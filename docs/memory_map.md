# Карта памяти STM32F407

Источник правды — [firmware/linker/stm32f407xx_flash.ld](../firmware/linker/stm32f407xx_flash.ld).

## Текущая раскладка

```
MEMORY {
  ROM    (rx)  : ORIGIN = 0x08000000, LENGTH = 1024K
  RAM    (xrw) : ORIGIN = 0x20000000, LENGTH = 128K
  CCMRAM (xrw) : ORIGIN = 0x10000000, LENGTH = 64K
}
```

| Регион   | Начало      | Размер  | Назначение |
|----------|-------------|---------|-----------|
| `ROM`    | 0x08000000  | 1024 КБ | Вся прошивка одним блоком: `.isr_vector` → `.text` → `.rodata` → `.ARM.*` → `LOADADDR(.data)` → `LOADADDR(.ccmram)`. Деления на bootloader / app / settings **нет** — см. ниже «Запланировано». |
| `RAM`    | 0x20000000  | 128 КБ  | SRAM1 (112 КБ) + SRAM2 (16 КБ) подряд, в линкере склеены в один регион. Сюда ложатся `.data`, `.bss`, newlib `_user_heap_stack` (Min Heap 512 Б, Min Stack 1024 Б). FreeRTOS `heap_4` (24 КБ из `configTOTAL_HEAP_SIZE`) тоже здесь — как обычный `static` массив в `.bss`. |
| `CCMRAM` | 0x10000000  | 64 КБ   | Объявлен как секция `.ccmram` (`AT> ROM` для копирования при старте), но в коде ни одна переменная пока не помечена `__attribute__((section(".ccmram")))`. Зарезервировано под task-стеки FreeRTOS / горячие данные (DMA через CCMRAM **нельзя** — bus matrix её не видит). |

`_estack = ORIGIN(RAM) + LENGTH(RAM) = 0x20020000` — main-stack растёт вниз
от этого адреса до старта `osKernelStart()`; после переключения в FreeRTOS
каждая задача получает собственный стек из `heap_4`.

## Что НЕ выделено отдельно

Линкер не размечает «Bootloader / App / Settings» — это сейчас один сплошной
ROM. Все запросы вида «прошить только app, не трогая загрузчик» / «положить
настройки в FLASH» **сейчас не поддерживаются на уровне сборки**. Ниже —
запланированное разбиение, которое потребует переписать `MEMORY {}`-блок и,
вероятно, добавить второй .ld-скрипт для бутлоадера.

## Запланировано (TBD)

| Регион    | Начало       | Размер   | Что туда планируется |
|-----------|--------------|----------|----------------------|
| Bootloader| 0x08000000   | 32 КБ    | Простой загрузчик с проверкой CRC и поддержкой UDS (см. `middleware/uds/` — пока заглушка). |
| App       | 0x08008000   | ~864 КБ  | Текущая прошивка целиком (после реализации загрузчика — без её первых 32 КБ). |
| Settings  | 0x080E0000   | 128 КБ   | Последний 128 КБ-сектор — эмуляция EEPROM в FLASH (хранить калибровку Hall, разрешение DS18B20 и т.п.). На сегодня модуль `middleware/settings/` из проекта удалён, EEPROM-эмуляции нет. |

При реализации этого разбиения нужно:
1. Разделить `ROM` в `.ld` на 3 региона (`BOOT`, `APP`, `SETTINGS`).
2. Привести таблицу выше в синхрон с реальностью (этот файл).
3. Обновить `make_release.py` / процедуру прошивки, если она будет
   собирать `.bin` отдельно для bootloader и app.
